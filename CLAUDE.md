# Феррум Строй — сайт

Одностраничный рекламный сайт компании **ООО «Феррум Строй»** (Пенза,
строительство сооружений из металлокаркаса). Продвигается через Яндекс.Директ.
Статический сайт: чистый HTML/CSS/JS, без фреймворков и сборки.

## Структура файлов

- `index.html` — весь одностраничник (hero, статистика, услуги, преимущества,
  процесс, галерея, секция «Обсудим ваш объект» с конфигуратором, подвал).
- `styles.css` — все стили.
- `script.js` — IIFE: авторасчёт «N лет на рынке», hero-анимация, конфигуратор
  каркаса (2D SVG + 3D canvas), cookie-баннер, цель `contact` в Метрике.
- `privacy.html` — политика конфиденциальности.
- `robots.txt`, `sitemap.xml`, `favicon.svg`, `images/`.

## Ключевые решения

- **152-ФЗ:** на сайте нет форм обратной связи и сбора ПДн. Контакт только по
  телефону. Есть cookie-баннер (кнопка «Принять» сохраняет согласие в localStorage).
- **E-mail полностью убран** — везде только телефон.
- **Конфигуратор «Соберите свой каркас»** (`#request`): 2D-чертёж (SVG, фасад с
  размерами) + вращающаяся 3D-изометрия (canvas). Типы объектов: Производственный
  цех, Складской комплекс, Навес, Здание / АБК, Ограждение, Индивидуальный проект.
  - Убраны тип «Ангар арочный» и кровля «Арочная» (по просьбе — никаких арок).
  - Плитки «Бюджет» и «Срок» убраны; показывается только ориентир по площади.
  - Ограждение: 9 материалов заполнения (профлист, двусторонний, евроштакетник,
    штакетник горизонтальный, жалюзи «Ранчо», сварная сетка, сетка-рабица,
    3D-сетка, кованые секции), у каждого свой 2D-паттерн и коэффициент цены.
    Производственный цех имеет аэрационный фонарь на коньке (отличие от склада).
- **Статистика (секция под hero):** «На рынке — N лет» (авто, от 27.01.2015,
  атрибут `data-years-since` + склонение в script.js), «География — Пенза и
  область», «Конструктив — Металлокаркас + панели», «Ресурсы — База · Техника ·
  Бригады». Цифр-заглушек `[XX]` быть не должно.
- **Реклама (38-ФЗ):** не ставим непроверяемые цифры («сдано N объектов» и т.п.).

## Осталось сделать оператору перед публичным запуском рекламы

- Подставить **ID счётчика Яндекс.Метрики** вместо `00000000` в `index.html`
  (переменная `COUNTER_ID`, три места: init, noscript-img, комментарий).
- Домен: canonical / og:url / og:image / `robots.txt` / `sitemap.xml` /
  `privacy.html` пока указывают на заглушку `ferrumstroy.example`. Если своего
  домена не будет — заменить на `https://prooferok.github.io/ferrumstroy/`;
  если будет — на реальный домен.
- Подать в Роскомнадзор уведомление об обработке ПДн (ст. 22 152-ФЗ) — действие
  оператора. `privacy.html` — типовой шаблон, желательно согласовать с юристом.
- Внутренние документы оператора ПДн (приказ + положение) были подготовлены в
  прошлой сессии как .docx, но **намеренно не хранятся в этом репозитории**, т.к.
  GitHub Pages публикует весь репозиторий (внутренние документы не должны попасть
  в открытый доступ).

## Тестирование

Скриншот-тесты гоняются через `playwright-core` с системным Chromium
(`/opt/pw-browsers/chromium`) во временной папке сессии (не в репозитории).
Запуск на реальном `index.html` через `file://`.
