# images

Папка для фотографий сайта.

## Как добавлять

1. Клади сюда файлы фото — латиницей, без пробелов в имени
   (например: `ceh.jpg`, `sklad.jpg`, `angar.jpg`, `abk.jpg`, `naves.jpg`).
2. Формат `.jpg` или `.webp` для фото; размер желательно до ~500 КБ.
3. Закоммить и запушь в ветку `claude/adding-images-koi9vc`.
4. Напиши, какой файл в какую карточку блока «Объекты» поставить.

Эту заметку можно удалить, когда появятся реальные фото.
